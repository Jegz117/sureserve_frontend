# Sure Serve Frontend

Frontend-only React + Vite + Tailwind project.

## Run in VS Code

1. Extract this folder.
2. Open the folder in VS Code.
3. Open Terminal.
4. Run:

```bash
npm install
npm run dev
```

Then open the localhost link shown in the terminal.

## Notes

- No backend is integrated yet.
- Login/logout uses React state only.
- Forms use local state and alert messages.
- Data is sample/static and backend-ready for future integration.
