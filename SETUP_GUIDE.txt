================================================================================
              SURESERVE - FULL SETUP GUIDE (Flask + MySQL + React)
================================================================================

This guide covers everything you need to install and run the SureServe
Electronics Service Provider website on your local machine (Windows).


================================================================================
  STEP 1: INSTALL PREREQUISITES
================================================================================

You need THREE things installed:

  1. Python 3.10 or higher
  2. MySQL 8.0 or higher
  3. Node.js 18 or higher

Download links:

  Python:  https://www.python.org/downloads/
           → During install, CHECK "Add Python to PATH"

  MySQL:   https://dev.mysql.com/downloads/installer/
           → Choose "MySQL Server" (Community Edition)
           → During install, set root password to: SureServe@2026
             (or change it in backend_flask/.env later)

  Node.js: https://nodejs.org/
           → Download the LTS version


================================================================================
  STEP 2: SET UP THE DATABASE
================================================================================

Option A — Using MySQL Command Line:

  1. Open Command Prompt or PowerShell
  2. Run:

     mysql -u root -p

  3. Enter your MySQL root password (SureServe@2026)
  4. In the MySQL shell, run:

     source C:/Users/Administrator/Documents/SURE SERVE CURRENT FILE/sureserve_frontend/backend_flask/init.sql

  5. Type: exit

Option B — Using MySQL Workbench:

  1. Open MySQL Workbench
  2. Connect to your local MySQL server
  3. Open File → Open SQL Script
  4. Navigate to: sureserve_frontend/backend_flask/init.sql
  5. Click the lightning bolt (⚡) to execute
  6. Verify database "sureserve_db" was created in the left panel


================================================================================
  STEP 3: CREATE THE SELLER/ADMIN ACCOUNT
================================================================================

Since the seed password in init.sql is a placeholder, you need to create
a real provider account. After the backend is running (Step 4), you can:

Option A — Use the Python script below:

  1. Open Command Prompt in the backend_flask folder
  2. Run:

     python -c "import bcrypt; print(bcrypt.hashpw(b'admin123', bcrypt.gensalt()).decode())"

  3. Copy the output hash
  4. In MySQL, run:

     USE sureserve_db;
     UPDATE users SET password = '<paste_hash_here>' WHERE email = 'seller@techking.com';

  Or simpler — just register via the API after starting the backend:

     curl -X POST http://localhost:5000/api/auth/register ^
       -H "Content-Type: application/json" ^
       -d "{\"fullName\": \"TechKing Store\", \"email\": \"seller@techking.com\", \"password\": \"admin123\", \"role\": \"provider\"}"


================================================================================
  STEP 4: INSTALL & RUN THE FLASK BACKEND
================================================================================

  1. Open Command Prompt or PowerShell

  2. Navigate to the backend folder:

     cd "C:\Users\Administrator\Documents\SURE SERVE CURRENT FILE\sureserve_frontend\backend_flask"

  3. (RECOMMENDED) Create a virtual environment:

     python -m venv venv
     venv\Scripts\activate

  4. Install Python dependencies:

     pip install -r requirements.txt

  5. Initialize the database (if not done in Step 2):

     python init_db.py

  6. Start the Flask server:

     python app.py

  7. You should see:

     * Running on http://0.0.0.0:5000

  8. Test it by opening in your browser:

     http://localhost:5000/

     → Should show: {"message": "SureServe Flask backend is running"}

     http://localhost:5000/api/test-db

     → Should show: {"message": "MySQL Connected Successfully", "success": true}


================================================================================
  STEP 5: INSTALL & RUN THE REACT FRONTEND
================================================================================

  1. Open a NEW Command Prompt or PowerShell window (keep backend running)

  2. Navigate to the frontend folder:

     cd "C:\Users\Administrator\Documents\SURE SERVE CURRENT FILE\sureserve_frontend"

  3. Install Node.js dependencies:

     npm install

  4. Start the development server:

     npm run dev

  5. You should see:

     VITE v5.x.x  ready in Xms
     ➜  Local:   http://localhost:5173/

  6. Open your browser to:

     http://localhost:5173/


================================================================================
  STEP 6: TEST THE APPLICATION
================================================================================

  BUYER FLOW:

    1. On the login page, click "Create Account"
    2. Fill in your name, email, and password
    3. After success, sign in with those credentials
    4. You'll see the Buyer Dashboard with real data
    5. Try "Installation Request" → Submit a service request
    6. Try "Submit Support Ticket" → Submit a ticket
    7. Go to "Recent Tickets" → See your submitted tickets
    8. Go to "Profile" → Update your name/email/phone/address
    9. Toggle dark mode from the Profile page

  SELLER/ADMIN FLOW:

    1. First, create a provider account (see Step 3 above)
    2. Go to: http://localhost:5173/seller-login
    3. Log in with: seller@techking.com / admin123
    4. You'll see the Seller Dashboard with stats from the database
    5. "Manage Requests" shows service requests from all buyers
    6. "Manage Tickets" shows support tickets from all buyers
    7. Use the ⋮ menu to mark items Finished or Cancelled
    8. "Analytics" shows performance metrics
    9. Export data as CSV from the table pages

  PREMIUM PAGE:

    The Premium page shows pricing plans (Free/Professional/Enterprise).
    This is currently a static marketing page — payment integration
    (e.g., Stripe/PayMongo) can be added as a future feature.


================================================================================
  CONFIGURATION (.env FILE)
================================================================================

  The backend configuration is in: backend_flask/.env

    PORT=5000              ← Flask server port
    DB_HOST=127.0.0.1      ← MySQL host
    DB_USER=root           ← MySQL username
    DB_PASSWORD=SureServe@2026  ← MySQL password
    DB_NAME=sureserve_db   ← Database name
    JWT_SECRET=sureserve_secret_key  ← JWT signing secret

  Change these values if your MySQL credentials are different.

================================================================================
  TROUBLESHOOTING
================================================================================

  ❌ "mysql is not recognized as a command"
     → Add MySQL bin folder to your PATH:
       C:\Program Files\MySQL\MySQL Server 8.0\bin

  ❌ "pip is not recognized"
     → Reinstall Python and CHECK "Add Python to PATH"

  ❌ "Access denied for user 'root'"
     → Check DB_PASSWORD in backend_flask/.env matches your MySQL root password

  ❌ "Cannot connect to backend server" in the browser
     → Make sure Flask is running (python app.py) on port 5000

  ❌ "CORS error" in browser console
     → Flask-CORS is already configured. Restart Flask if needed.

  ❌ Frontend shows blank page
     → Open browser DevTools (F12) → Console tab for errors
     → Make sure npm install completed without errors
